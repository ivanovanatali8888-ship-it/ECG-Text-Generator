# ECG Text Generator

A small real-time ECG waveform generator made with Python.

Type an ECG sequence and watch it turn into a continuously scrolling ECG-style signal.

### Features

* Real-time ECG waveform
* Live text editing
* BPM, amplitude and noise controls
* RU / EN interface
* Pause / resume
* Built-in symbol guide
* Standalone Windows `.exe`

### Download

The ready-to-use Windows version is available in **Releases**.

Just download `ECG_Generator.exe` and run it.

### Source

The Python source code is included in this repository.
